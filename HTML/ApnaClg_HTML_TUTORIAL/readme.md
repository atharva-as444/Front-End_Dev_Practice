# Basic HTML Project

## 📖 Overview
This is my **HTML Learning Project**, created to practice and experiment with **HTML & CSS basics**.  
I started with an HTML tutorial, but for CSS I did **not follow any tutorial** — instead, I explored properties on my own and experimented to style different pages.  
This project reflects my curiosity, self‑learning, and dedication.

---

## 🛠️ Features
- **Homepage** → Clean layout with footer (`HTML LEARNING PROJECT` + `ATHARVA SINGH`).  
- **Student Data Page** → Table with styled rows (blood group highlighting).  
- **Extra Page** → Scroll effect and creative CSS tweaks.  
- **Heavy CSS Page** → Tried multiple CSS properties without guidance, purely self‑exploration.
